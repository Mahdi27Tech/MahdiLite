A proxy server that fits in your pocket.

MahdiLite runs a forwarding proxy on your Android phone, much like Squid does on a server. Point other devices at it and their web traffic passes through your phone, with a cache, a password and a block list that you control.

Download the app (APK) Read the user manual

Free. Android 7.0 or newer. No account, no root, no ads.

How it works

A forwarding proxy is a middleman. Your devices ask it for a page, it fetches the page, and it hands the answer back. MahdiLite does that from your phone.

  1. Start

    Choose a port, set a password if you want one, and start the proxy. A notification shows that it is running.

  2. Point

    On a laptop or another phone, open the Wi-Fi proxy settings and enter your phone's address and the port.

  3. Browse

    Pages now travel through your phone. Repeated requests can come from the cache, and blocked sites are refused.

What it does

HTTP and HTTPS
Handles normal web requests and HTTPS tunnels (the CONNECT method). HTTPS stays encrypted from your device to the website.
Response cache
Keeps copies of cacheable pages so a second device can get them without a second download. You can switch the cache off, check its size and clear it.
Password protection
Ask every client for a username and password (Basic proxy authentication) before it can use your phone.
Allowed clients
Limit the proxy to the devices you list, so a stranger on the same network cannot use it.
Blocked domains
Refuse requests to sites you name. Useful for ads, trackers or sites you do not want on your network.
Live statistics
See total requests, data sent and received, active connections and cache hits while the proxy runs.
Runs in the background
Works as a foreground service with a notification, so Android is less likely to stop it when you switch apps.

Install the app

MahdiLite is installed from an APK file. Only the phone that runs the proxy needs the app. The other devices just change a Wi-Fi setting.

Android 7.0 or newer. About 5.5 MB.

Download the app (APK)
  1. Tap Download the app (APK) and download the file.
  2. Open the downloaded file. If Android asks, allow your browser or Files app to install apps.
  3. Tap Install. Because the app is not on Google Play, Android may show a warning. Continue only for a file you downloaded from this page.
  4. Open MahdiLite. Allow notifications when asked, so the running notice can appear.

User manual

Starting the proxy

  1. Open MahdiLite and choose a port between 1024 and 65535. If you are unsure, use 8080.
  2. Optional: turn on password protection and set a username and password.
  3. Optional: add the devices that are allowed to connect, and any domains you want blocked.
  4. Leave the cache on to save data, or switch it off if you always want fresh pages.
  5. Start the proxy. The notification MahdiLite proxy running appears. Note your phone's address on the network.

Connecting another device

Your phone and the other device must be on the same Wi-Fi network. In the other device's proxy settings choose manual, then enter your phone's address as the host and your port.

  • Android: Settings, Wi-Fi, long-press your network, Modify network, Advanced options, Proxy, Manual.
  • iPhone or iPad: Settings, Wi-Fi, the (i) beside your network, Configure Proxy, Manual.
  • Windows: Settings, Network and internet, Proxy, Manual proxy setup, Set up.
  • macOS: System Settings, Network, your Wi-Fi, Details, Proxies, then switch on Web proxy (HTTP) and Secure web proxy (HTTPS).

If you turned on a password, your browser or device asks for the username and password the first time it uses the proxy.

Testing from a computer

A quick way to check that everything works. Replace the address, port and login with your own.

curl -x http://192.168.1.23:8080 http://example.com

# with a password
curl -x http://192.168.1.23:8080 --proxy-user name:password https://example.com

Good to know

  • Only plain HTTP pages can be cached. HTTPS goes through an encrypted tunnel that the proxy cannot read.
  • The statistics show requests, data up and down, active connections and cache hits. Use them to see whether the cache is helping.
  • Clear the cache whenever you want a clean start.
  • Some phones stop background apps to save battery. If the proxy keeps stopping, set MahdiLite to unrestricted battery use in Android settings.
  • Stop the proxy when you are done. A stopped proxy cannot be used by anyone.
Keep your proxy private

A proxy with no password lets anyone on the same network use your phone's connection. On a shared or public Wi-Fi, turn on the password and the allowed clients list first, or do not run it at all. Use MahdiLite only on networks and devices you own or are allowed to manage.

Questions

Is this the same as Squid?

It follows the same idea: a forwarding proxy with a cache and access rules. MahdiLite is far smaller and made for a phone. It does not try to replace everything Squid can do on a server.

Can MahdiLite see my HTTPS traffic?

No. For HTTPS it opens a tunnel and passes the encrypted data through, so it cannot read pages, passwords or messages inside it. It can only see which site a device asked to reach.

Do I need root or a VPN profile?

No. Nothing is installed on the other devices. You only change the proxy setting for your Wi-Fi network on each one.

The other device cannot connect. What should I check?

Make sure both devices are on the same Wi-Fi, the proxy is running, and the address and port match exactly. If you set allowed clients, check that the device is on the list. If you set a password, check the username and password. Some public and guest networks stop devices from talking to each other, and then no proxy on that network will work.

The proxy keeps stopping when my screen is off.

Your phone is probably saving battery by closing background apps. Allow MahdiLite unrestricted battery use in Android settings and keep its notification visible.

Can I use it from outside my home network?

MahdiLite is meant for your local network. Making it reachable from the internet exposes your phone, so it is not recommended.

Does it work on iPhone?

The app itself is for Android. An iPhone, a computer or any other device can still use an Android phone running MahdiLite as its proxy.

Is it free? Does it collect my data?

It is free and needs no account. It asks only for network, Wi-Fi state and notification access.
